# Texture credits
- `moon.jpg` — from the three.js examples (https://github.com/mrdoob/three.js, MIT repo).
- `mars.jpg` — from threex.planets (https://github.com/jeromeetienne/threex.planets, MIT repo).

I could not verify the original upstream licence of the image data. Before using this site commercially,
swap in maps with a clear licence, e.g. NASA imagery from https://svs.gsfc.nasa.gov/ or https://solarsystem.nasa.gov/.
Any `moon.(jpg|png|webp)` / `mars.(jpg|png|webp)` in this folder is picked up automatically (equirectangular, 2:1).
If a file is missing the site falls back to a generated crater texture.
